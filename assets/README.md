# assets/

Binary game data embedded into the build. **Do not edit these files by hand.**
Every file except this README is generated by `cargo xtask import-assets` and
guarded by `manifest.txt` and the test `xtask/tests/asset_manifest.rs`; a
change made by hand makes `cargo test --workspace` fail.

## Origin

The data is read, as data, from the C source tables of
[sobomax/digger](https://github.com/sobomax/digger) at the pinned commit
`638125eecc2a36629b886f58d7b75253894cf3d3`:

| File | Upstream source | Content |
|---|---|---|
| `sprites.bin` | `vgagrafx.c` | the 120 VGA sprite images and masks |
| `font.bin` | `alpha.c` | the 40 VGA font glyphs |
| `title.zz` | `title_gz.c` | the title picture, zlib stream copied verbatim |
| `icon.rgba` | `icon.c` | the 64x64 window icon |
| `index.rs` | (generated) | sprite and glyph index included by `digger-core` |
| `manifest.txt` | (generated) | SHA-256 digest and length of every file above |

No upstream code is compiled, linked or run. The graphics are Andrew Jenner's
redrawn Digger Remastered art as carried by upstream; CGA data is not
imported.

File formats, and how to re-import and check, are described in
[`docs/assets.md`](../docs/assets.md).
